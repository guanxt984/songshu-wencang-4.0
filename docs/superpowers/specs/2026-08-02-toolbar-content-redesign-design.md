# 工具栏内容重制设计

## 目标

保留“添加松果 / 编辑文档 / 全部重新整理”三个功能，重制工具栏的图标、文字排版与趴伏松鼠素材，使松鼠真正压住工具栏上边沿，三个按钮内容保持水平、端正和稳定。

## 松鼠素材

- 生成新的横向趴伏松鼠透明 PNG，沿用当前橙棕色蜡笔插画 IP。
- 松鼠腹部贴近水平边沿，两只前爪明确越过并压住边沿，尾巴向右自然展开。
- 使用紧边界画布，透明区域仅保留必要呼吸空间，避免 CSS 尺寸与视觉主体尺寸失真。
- 页面中松鼠位于第三个按钮上方偏右，不遮挡按钮文字。

## 工具栏内容

- 工具栏固定为三等分按钮，不增加折叠入口。
- 三个按钮保留现有功能与文字。
- 按钮文字使用现有正文无衬线字体，不使用手绘标题字体；统一字重、字号、行高与水平基线。
- 每个按钮采用“固定图标盒 + 单行文字”的水平布局；图标不旋转，视觉尺寸一致。
- 图标继续使用项目现有 PNG 资产，借助统一容器尺寸校正原始图片的视觉差异。

## 交互与响应式

- 默认与 hover 状态的按钮、文字、图标和松鼠几何位置完全一致。
- hover 只改变背景、边框和阴影；键盘焦点提供清晰轮廓。
- 窄屏继续保持三列，降低间距与字号但不换行、不重叠。
- `prefers-reduced-motion` 下取消工具栏视觉过渡。

## 验收

- 松鼠腹部和双爪与工具栏上边沿产生明确重叠，不再悬空。
- 三组文字处于同一水平基线，字形端正，无旋转或倾斜布局。
- 三个图标的视觉中心、占位尺寸和文字间距一致。
- 桌面、hover 和窄屏状态下不发生跳位、换行、遮挡或溢出。
- 自动化契约和完整项目检查通过，浏览器控制台无错误。
